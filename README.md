## Hi there 👋

# 👨‍💻 От батников — к настоящим программам

Мой путь начался с обычных `.bat`-файлов. Тогда я просто развлекался: создавал скрипты, которые выводили смешные сообщения или неожиданные предупреждающие окна. Это было забавно, но быстро перестало приносить удовлетворение. Я захотел создавать нечто большее — программы, которые действительно упрощают жизнь, автоматизируют рутину и решают задачи, а не просто развлекают.

Сейчас я разрабатываю ПО для компьютеров. Мой основной инструмент — **Python**, на нём я пишу десктопные приложения (с использованием Tkinter, PyQt и других библиотек), а также мини-игры и лаунчеры для игр. Например, интерфейс лаунчера для Minecraft я делаю на Python, а для запуска самой игры используется **Java** и система сборки **Gradle**. Также я использую **Java** для бэкенд-сервисов, а веб-интерфейсы делаю на **HTML/CSS**. Параллельно постепенно осваиваю **C++** — он интересен мне для задач, где важна производительность, но пока это уровень изучения, а не рабочего инструмента.

## 🛠 Чем занимаюсь сейчас

- **Десктопные приложения на Python** — это моя основная специализация. Пишу утилиты для офисных задач, автоматизацию работы с файлами, небольшие бизнес-приложения с графическим интерфейсом.
- **Мини-игры и лаунчеры на Python** — разрабатываю небольшие игры (аркады, головоломки) и лаунчеры для популярных игр. В лаунчерах Python отвечает за интерфейс и взаимодействие с пользователем.
- **Запуск игр (Java + Gradle)** — для запуска таких игр, как Minecraft, используется Java и система сборки Gradle. Я настраиваю процесс запуска, управление версиями и модами.
- **Бэкенд на Java** — REST API, обработка данных, интеграции. Использую, когда нужна надёжность и масштабируемость.
- **Фронтенд на HTML/CSS** — для веб-обёрток своих десктопных проектов или простых сайтов-портфолио.
- **Изучаю C++** — читаю документацию, решаю задачи, пробую писать небольшие консольные программы. В перспективе хочу использовать его для высоконагруженных модулей.

Помимо классической разработки, меня привлекает **искусственный интеллект**. Я изучаю машинное обучение на Python, экспериментирую с библиотеками, но отношусь к этому как к дополнительному инструменту. Моя философия: ИИ хорош там, где он действительно нужен, но не стоит заменять им простые и надёжные решения. Поэтому я продолжаю писать и обычные программы, и те, где ИИ может дать реальную пользу (например, предсказательная аналитика или обработка текста).

## 🎯 Ближайшие планы

- Продолжать развиваться в разработке десктопных приложений на Python, улучшать архитектуру и интерфейсы.
- Расширять функциональность лаунчеров: добавлять автоматическую установку модов, обновление клиента.
- Завершить базовое изучение C++ и применить его в реальном проекте (например, написать быстрый модуль для обработки данных).
- Изучить **Go** — присматриваюсь к нему для сетевых сервисов, планирую сделать pet-проект, чтобы понять его сильные стороны.
- Углубиться в практическое применение ИИ, но без фанатизма — только там, где это оправдано.

---

## 💡 Мои принципы

- Программа должна приносить пользу — это главное.
- Чистый код и понятная архитектура — уважение к тем, кто будет читать его после меня.
- Никогда не останавливаться в изучении нового, но не гнаться за модными технологиями без необходимости.
